# Feature-to-backend audit

Baseline preserved: `f4fbd3e40427932b69fd26e6965f915cef602e54`. The backend is **Kotlin/Ktor**, not Node.js. All paths below are under `/api/v1`. “DB verified” means an isolated PostgreSQL integration test, not a live Render or Moto G60 acceptance test. Cloud mode does not fall back to local success fixtures when the server rejects a mutation.

The new cart and lifecycle endpoints only serve the **individual Main Canteen prepared-food demo**. Seller-visible “accepted/ready/completed” states are simulations, not paid orders, stock reservations or kitchen dispatch. No production readiness claim follows from this matrix.
