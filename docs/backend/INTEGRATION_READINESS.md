## Isolated verification environment and current results

Use `backend/README.md` and `.env.example`, copying only to ignored private `backend/.env`; generate a unique local password. Keep app and test DB names distinct. This preparation used a disposable PostgreSQL 16 Alpine Podman container bound to `127.0.0.1:5434`, with `rit_canteen_dev` and a separate `rit_canteen_test`; it did not use or mutate another team's database. `RIT_ENV=local`, `DEMO_SEED_ENABLED=true` applies only to the disposable app DB. The test suite receives `RIT_TEST_DATABASE_URL`, `RIT_TEST_DATABASE_USER`, `RIT_TEST_DATABASE_PASSWORD` for the disposable test DB. Never commit `.env`, token, password, dump or volume.

Actual clean command from `backend/`: `./gradlew clean build --no-daemon --max-workers=1` with those test DB variables exported. Result: **BUILD SUCCESSFUL; 13 tests, 0 failures, 0 errors, 0 skips** (4 config, 4 foundation, 5 auth integration). Real PostgreSQL was connected, not skipped. The tested foundation includes migrations/seeds, the frozen auth/profile JSON, eight distinct demo identities and hashed passwords, role separation, supervisor/capability revocation, account/session invalidation, profile persistence and no-seed mode.

Reusable script: `backend/scripts/verify-integration.sh` (requires Bash, curl, jq and the Gradle wrapper). It refuses non-loopback URLs, non-local demo mode, identical app/test URLs, and runs only after both `RIT_INTEGRATION_DISPOSABLE_APP_DB=YES` and `RIT_INTEGRATION_DISPOSABLE_TEST_DB=YES` are set. With all variables exported from the private `.env`, run `bash backend/scripts/verify-integration.sh` for clean build plus live smoke; `--smoke-only` performs only distribution preparation and smoke. It does not create databases, hide test skips, mutate migrations, or test unimplemented routes. The script uses a unique disposable registration identity and stops its own server; use it only with a disposable app DB.

Actual live smoke against Netty and the disposable app DB passed `/health` 200, `/ready` 200, register 201 without bearer, login 200, `auth/me` 200 without bearer in the response, profile GET 200, profile PATCH 200 (including explicit null department), logout 204 empty, and revoked-token `auth/me` 401 `UNAUTHENTICATED`.
